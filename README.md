# 🍔 Swiggy Food Delivery Sales & Performance Dashboard

An interactive Microsoft Excel dashboard designed to analyze food delivery sales, customer ratings, and regional trends across a dataset of ~197,000+ orders.

---

## 📌 1. Brief Summary
This project evaluates Swiggy's transactional delivery data to uncover high-performing cities, popular food categories, and customer satisfaction patterns using advanced Excel features.

---

## 📖 2. Project Overview
The food delivery industry generates massive volumes of operational data daily. This project processes raw transactional records to build an executive-level dashboard that tracks gross revenue, order distribution by day/month, and top-performing restaurant chains.

---

## 🎯 3. Problem Statement
Stakeholders need visibility into regional sales performance and customer preferences to optimize marketing and restaurant partnerships. This project answers key business questions:
* Which cities and regions contribute the highest revenue?
* What are the top-selling food categories and restaurant partners?
* How do customer ratings and average order values (AOV) fluctuate across quarters?

---

## 🗂️ 4. Dataset Description
* **Source:** Swiggy food delivery sample dataset.
* **Size:** ~197,430 rows of transactional order data.
* **Key Columns:** `State`, `City`, `Order Date`, `Month`, `Quarter`, `Restaurant Name`, `Category`, `Dish Name`, `Food Type`, `Price (INR)`, `Rating`, and `Rating Count`.

---

## 🛠️ 5. Tools & Technologies Used
* **Microsoft Excel:** Data Cleaning, PivotTables, XLOOKUP / Formulas.
* **Data Visualization:** Custom Dashboard Layout, PivotCharts, Slicers, and Conditional Formatting.
* **Version Control:** Git & GitHub for portfolio management.

---

## ⚙️ 6. Methods & Workflow
1. **Data Cleaning & Validation:** Inspected raw data for missing values, formatted dates properly, and ensured numerical consistency.
2. **Data Analysis (`ANALYZE` Sheet):** Built summary tables and PivotTables to aggregate total sales, order counts, and average ratings by city, month, and food type.
3. **Dashboard Design:** Created an executive color-themed UI featuring KPI summary cards, regional mapping visuals, and dynamic slicers.

---

## 💡 7. Key Insights & Findings
* **Top Revenue Hubs:** Bengaluru, Lucknow, Hyderabad, and Mumbai drive the highest transaction volumes and gross sales.
* **Total Scale:** Analyzed over ₹5.3 Crore in gross transactional value across multiple food categories.
* **Customer Feedback:** Maintained an average platform rating of ~4.34, showing strong overall user satisfaction.

---

## 🖼️ 8. Dashboard Output & Features
* **Dynamic Slicers:** Interactive filtering by Month, Quarter, and Food Type (Veg / Non-Veg).
* **KPI Summary Cards:** Instant visibility into Total Sales, Total Orders, Average Order Value (AOV), and Average Rating.

---

## 🚀 9. How to Run This Project
1. Download the `SWIGGY PROJECT.xlsx` file from this repository.
2. Open the file in Microsoft Excel.
3. Navigate to the **DASHBOARD** sheet.
4. Use the interactive slicers on the left side to filter data dynamically in real-time.

---

The dashboard successfully bridges raw data and actionable business insights. It provides stakeholders with an intuitive interface to monitor sales health instantly, proving the utility of advanced Excel for business intelligence reporting.
